# hub-bot v2 面板布局原型

一次性 UI 原型，用于评议 [Panel 目标形态草案](https://github.com/Ghost233/GhostDSHHubBot/issues/24)。仅留存于 `fix/24-panel-v2-prototype` 分支，不合并或发布。

## 打开

在此 worktree 执行 `npm run prototype:panel`（macOS），或直接用浏览器打开同目录的 `prototype-v2.html`。无安装、构建或服务器要求。

三个方案使用同一页面：`?variant=A` 待办优先；`?variant=B` 负责人工作区；`?variant=C` 运行时间线。底部切换栏及左右方向键可循环切换，输入时不拦截方向键。

## 可以评议什么

- A：先回答需要我处理什么，再看进展、结果、负责人和下次唤醒。
- B：先选仓库负责人，在一个工作区内处理任务、会话和定时器。
- C：沿运行时间线追查事件、结果及通知去向，侧栏保留待办。

共用页面包括负责人列表、定时器、运行记录和连接设置。可尝试项目筛选、任务搜索、确认与回复、暂停/恢复/取消定时器，以及带摘要或不带摘要的手动换实例流程（含等待空闲、准备失败，以及切换绑定后归档失败与重试）。深浅色切换和恢复初始场景位于顶部。

## 原型约束

所有条目均为示例数据，状态仅在内存中；没有网络/API 调用，不读取 token，不写 profile 或真实 Bot 状态。示例任务与报告不代表真实项目已完成这些变更。布局与模拟状态不等于产品实现。

- 记忆具体接入暂缓，设置页仅展示已确认的需求边界，没有虚假的有效开关。
- 定时器由负责人在对话中设定；面板只有查看、暂停、恢复、取消。
- 发送成功表示通道接受，不代表已读；未通知与发送失败分别呈现。
- 换实例先准备、后绑定、再归档；默认只带事实清单，额外摘要须先预览确认；L3 与 timer 会话不受影响。
- 待验收结果展示报告与会话入口，本原型未增加面板验收功能。
